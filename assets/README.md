# Brand assets

| File | Use |
|---|---|
| `logo.png` | Full logo with wordmark (source artwork) |
| `logo-mark.svg` | Mark only, transparent, for dark backgrounds |
| `icon.svg` | Mark on a dark rounded tile, for app icons |
| `favicon-16.png`, `favicon-32.png` | Browser tab (16px uses a heavier outline) |
| `apple-touch-icon.png` | iOS home screen (180px) |
| `icon-512.png` | PWA / large icon |
| `avatar.png` | GitHub and npm avatar (1024px, square) |
| `social-preview.png` | GitHub social preview and link cards (1280×640) |

Colors: background `#060708`, white `#FFFFFF`, cyan `#28EAEC`.
